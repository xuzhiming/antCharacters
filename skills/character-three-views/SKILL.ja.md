# バランス調整用の全身三面図

部位画像は元絵の1枚絵をデザインの基準にして先に制作します。このSkillは、その後にモデル編集で重ねる全身の正面・本人右側面・背面を作ります。三面図を先に作って部位画像の制作基準へ置き換えたり、三面図に合わせて元絵・部位画像・3Dモデルを変更したりしません。

## 入力と制作

1. 元絵と完成した頭（髪込み）・体の画像を表示します。元絵は顔立ち、髪型、衣装、配色、頭身のデザイン基準、完成した部位画像は方向・構造・塗りの整合確認に使います。部位画像ごとの画面占有率を頭と体の実寸比と解釈しません。
2. [部位・方向の契約](../character-parts-images/references/part-contract.md)の本人左右、直立した通常顔、Tポーズ、足間隔を引き継ぎます。全身には髪の全長、衣装、手足、靴を含めます。側面は本人の右側で、鼻・胸・つま先の前方は画面右です。非対称を左右反転で複製しません。
3. 内蔵image_genと利用可能なimagegenスキルを使い、[生成指示](references/prompts.md)で1回につき1方向・1個体を生成します。使用できる元絵と採用済み画像だけを明示して入力します。[共通の塗り基準](../character-material-brushup/references/painting.md)に沿い、既に完成した部位の表現を引き継ぎます。三面図のために新しい塗り方や装飾を追加しません。塗りの改善を依頼された場合だけ[character-material-brushup](../character-material-brushup/SKILL.md)へ進みます。
4. 正面を基準に、側面・背面でも頭頂、顎、首、肩、腰、膝、靴底の高さ、頭身、髪丈を揃えます。同じ寸法・尺度・余白で、全輪郭を収めた実際のアルファ付きPNGを3枚保存します。透視の誇張、文字、寸法線、市松模様を描き込みません。コードによるパーツの継ぎ貼りや輪郭変形を描き直しの代用にしません。

生成した3枚を表示し、元絵のデザインと頭身、完成部位との整合、首のつながり、本人左右、同じ足元の基準を確認します。隠れた面の補完は推定として扱います。同じ問題を2回修正して改善しなければ連続編集を止め、残差を伝えます。三面図は比率を合わせる参考で、3Dの一致を検証したとは報告しません。

## 保存とアプリへの自動連携

ローカルの一括images依頼では、8枚を `scripts/update-images.mjs` で登録した後、[登録形式](references/delivery.md)に従い `scripts/update-three-views.mjs` で**同じ正本**へ3枚を登録します。三面図の登録まで済ませてから依頼文のcompleteを実行します。アプリが正本を再読み込みし、モデル編集で自動表示します。モデルが用意されていれば初回だけ透過余白を除いて全高・足元へ仮合わせし、以後の手動調整値は保持します。

独立した画像ZIP納品では、8枚と三面図3枚を `scripts/package-images.mjs` の `threeViews` へまとめます。三面図だけの依頼は `update-three-views.mjs` を使い、部位画像を作り直しません。実プロンプトを保存し、元絵の複製、第三者画像、履歴、説明用HTMLを同梱しません。
