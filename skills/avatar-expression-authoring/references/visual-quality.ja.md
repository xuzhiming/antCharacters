# 仕上がりを判断する

お手本と作業モデルを同じ条件で見ます。最初に顔全体の印象を、次に差が大きい部分を見ます。「自然」「可愛い」だけで済ませず、目標と違う線や面を特定して次の編集へつなげます。

| 見るもの | 目標との差の例 | 次の編集の考え方 |
| --- | --- | --- |
| 閉じ目の弧と目尻 | 直線すぎる、外側が鋭く落ちる | 中央と両端の移動量を変え、周囲も選んで弧をつなぎます。 |
| 眉と顔全体の印象 | 穏やかな閉眼のはずが困り顔・悲しい顔になる | 通常顔と重ねて眉の位置・傾き・曲率を戻し、その下の皮膚を再調整します。 |
| 瞼の厚みと曲面 | 腫れぼったい、前へ浮く、眉下に溝 | 横と両45度で、瞼から額への前後位置を周囲へなだらかに配ります。 |
| まつ毛と皮膚 | 線が伸びる、帯が折れる、根元に隙間 | 部品を順に調整し、複数列に配ります。局所固定が別の場所を伸ばしていないかも見ます。 |
| 口の輪郭と表情 | 口角だけ上がる、中央が硬い、開き方が違う | 上下唇の弧・厚み・口角・頬を合わせて編集します。 |
| 本人らしさと途中 | 最大強度だけ良い、通常顔と印象が違う | 鑑賞サイズで比べ、途中強度・髪付きへ戻って意図しない表情変化を直します。 |

## 判断から編集へ戻る

「閉眼は成立したが目標より眉が低く悲しそう。眉の高さと弧を戻し、眉下を整える」と書けるなら、次の操作が見えています。比較画像に写る修正可能な差を、残件の説明だけで終わらせません。

大きな差が減った後は、鑑賞サイズでの印象を優先します。まつ毛の尖りや描き込みなどが通常顔にもあるなら、それを転送の不具合と決めつけません。元のデザインとユーザーの許容範囲を尊重し、自然で可愛い表情に達していれば完了します。近接で細部が見えることだけを理由に追加修正を続けません。

修正が必要な場合は、改善した試行を残し、悪化したら戻します。同じ操作で進まない時は視点・選択点・影響範囲・部品を変え、原因が怪しければ構造を確かめます。自動美観スコアや一律の画像誤差を完成基準にしません。

口内が元からない場合も、口縁が目標に近づくことを優先します。奥が見えることだけを理由に開きを弱め、必要な口形を失わないようにします。元モデルの口内構造の制約と、口縁の造形の良否は分けて説明します。

## 提示する時

目標に沿った輪郭・表情・可愛さを比較で示します。お手本側の構造上の無理や生成の揺れは、モデル側の不足と分けます。ユーザーが合格とした表現をエージェント独自の微細な基準で修正待ちへ戻しません。ログやテスト件数より、目標／修正前／仕上げ後と「どこをどう綺麗にしたか」を提示します。
