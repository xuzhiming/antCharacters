# 症状から修正へ進む

| 症状 | 先に確認するもの | 修正と再確認 |
| --- | --- | --- |
| 閉眼で困り顔・悲しい顔になる | 目標と通常顔を重ね、眉の位置・傾き・形を見る | 広い変形後に眉と周辺を戻し、眉下から瞼へなだらかに整えます。 |
| 元の口の線が上に残る／下側の面が無理に開く | ソリッド・斜め・小さな試し変形で本来の上下唇を探します | 誤った試行を戻し、確認した口縁から作り直します。口内の追加で隠しません。 |
| 瞼直上の面だけ縦に長い | 同じカメラのワイヤーで複数列の間隔を比較します | 影響範囲を眉側へ広げ、複数点の移動と周辺の戻しを重ねます。局所固定による集中も解きます。 |
| 模様が大きく伸びる | UVを変えず、まつ毛の描画と近傍面の辺長を見ます | 線ぎりぎりの頂点だけを引かず、広い範囲へ移動量を減衰させます。 |
| 閉じ目が腫れる／前へ突き出す | 真横と左右45度で皮膚・まつ毛・眼の深さを見ます | 外側の皮膚を基準にY相当の前後位置を整え、額から瞼へ曲率をつなぎます。軸は入力ごとに確認します。 |
| 上瞼の細い線が補正後も残る | ソリッドへ切り替え、テクスチャを外しても板状の隆起や段差が残るか見ます | 材質の線だけと決めつけず、隆起している皮膚の列を選んで局所を整えます。スクリプトの平滑化で改善しなければ、Blenderの通常編集へ切り替えて形を確認します。 |
| 黒い点・三角形・目尻の突起 | 面を選び、元の成分と奥行きを照合します | 毛の向き、帯の折れ、虹彩の貫通を切り分けます。推測を記録し、実形状で訂正します。 |
| まつ毛だけ動いて皮膚が残る | 接続成分と一部の癒着を確認します | 想定内です。次に皮膚を選び直して追従させ、接続部分の余分な変形を戻します。 |
| 開いた口の中央に歯や口内の部品が取り残される | 元からある部品と、上唇・下唇・顎への接続をソリッドで見ます | 上側に付く部分と下側に付く部分を分けて、作業キーで追従させます。中間強度と横からの厚みも確認し、部品や材質を新造して隠しません。 |
| 完全閉眼だけ良く、中間値が不自然 | 25/50/75%、左右45度・横と目口の組合せを見ます | 端の動き、厚み、眼との深さ、分離部品の追従を補正します。最大強度だけで完成にしません。 |
| 正面だけ一致し横が破綻する | 固定カメラの目標と現在像、側面の支持面を見ます | 目標のカメラずれと実形状の不一致を分け、前後を調整します。目標をワープして隠しません。 |

## 反復の記録

各試行に、症状、仮説、対象部位、操作と範囲、見た画像、観察、採用／取り消しを残します。数値の反転や辺の伸びは原因の手掛かりです。内側の眼窩と外側の皮膚を同じ領域で集計せず、元から細い辺や閉じる面も区別します。

「スクリプトが動いた」「反転数が減った」「操作点が一致した」を、かわいく自然な表情の評価へ置き換えません。逆に、診断値だけで見た目の良い試行を捨てません。対象とカメラを固定して、前後画像とワイヤーを判断の根拠にします。

## 再開の引き継ぎ

作業フォルダーに次を残します：入力の識別、対象キー、確認済みの部位と未確定部分、採用した保存地点、取り消した理由、最新の比較、残る症状、次に試す1操作。ユーザーの評価はエージェントの推測と区別します。汎用資料へ個人モデルの番号や作業パスを追加しません。

## 共通ツールの補間も検査します

奥行き補正の境界で灰色の三角形や段差が出たら、MToonとソリッドを同じ角度で見ます。外側の支持点の誤り、一律の深さによる部品の厚み消失、選択境界の急な切替を切り分けます。前後変位を戻し、選択と影響範囲を変え、前後も補正します。MToonで目立たないことだけで採用しません。

## 転送で対応が混ざる場合

- 開口するとスパイクや三角形が出る：上下の口縁が逆、または近接した唇を同じ面へ対応させていないか見ます。上下の弧を別々に指定し、対応の撮影に戻ります。元の頂点番号を別モデルへ持ち込みません。
- Surface Deformが非凸面でbindできない：三角化するのは一時ドライバーだけです。元の顔を三角化して解決しません。
- 眉で上瞼が伸びる：皮膚まで眉ドライバーへ直接接続せず、転送済み眉の変位を皮膚へ配り、目の縁を保護します。保護の近くが急に伸びたら範囲と分散を見直します。
- 眉を元に戻した境界が折れる：高さのしきい値で急に変位を切らず、眉から瞼へ複数列を使って変位をつなぎます。部品の眉だけでなく皮膚に描かれた線も、通常顔と照合します。
- ブラウザーでポーズが見えない：撮影対象、キーの強度、再読込したファイルを確認します。保存ファイルのドライバーが無効なだけなのか、実際の形状が動いていないのかを区別します。撮影用コピーを合格品そのものと取り違えません。

- 画像の目印は合うのにマスクが奥へ沈む：開口越しのraycastが奥の皮膚へ当たっていないか45度・横で見ます。投影成功を解剖学的な正解とせず、目縁の実頂点の世界座標へ置き直します。
