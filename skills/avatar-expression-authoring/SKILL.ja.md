# 表情を、そのモデルらしく綺麗に仕上げる

目標は、見本に近い自然で可愛い表情です。転送・保存・テストの成功は完成の判定ではありません。エージェントが画像と構造を見て部位を決め、同梱ツールが反復計算を行い、必要な箇所をBlenderで仕上げます。

元モデルのまつ毛の尖りなど、そのモデルの表現と転送で生じた崩れを通常顔との比較で分けます。鑑賞サイズで自然で可愛く、ユーザーの許容範囲に達していれば完成です。近接で粗さが見えるだけで修正を必須にせず、追加のComputer Useは必要な場合に使います。

## 制作の流れ

1. **顔を見る。** 現在のモデルから作業コピーを作り、顔の向きと撮影範囲を合わせます。最初に髪付きの通常顔と、皮膚・まつ毛・眉・本来の口縁を見ます。構造はソリッド／ワイヤー、印象はMToon＋Standardで確認します。対象が分かれば、自動検出や不要な一覧作成は挟みません。[準備・撮影・保存](references/commands.md)。
2. **対応を指定して土台を作る。** [転送の手順](references/transfer.md)を読み、必要な部位だけ進めます。目は皮膚だけのマスクへ8点と追従部品を指定します。口は上下の口縁を別々に確認し、その弧へ動きを転送します。眉は左右の独立部品を指定します。全表情の依頼なら同梱8眼・10口・5眉を使えます。フィットを画像で確認してから一括転送します。
3. **見本と比べて直す。** まず代表の閉眼・あ・笑顔・怒り眉を見て、共通のずれはフィットへ戻って直します。個別の目尻・厚み・口角はComputer Useによる通常編集も使います。準備・撮影はスクリプトやMCP、形の判断は画像、局所仕上げはやりやすい操作手段を選びます。すべてをクリック／すべてをCLIに統一しません。
4. **仕上がりを提示する。** 各表情を通常顔と見比べ、左右45度・真横・中間強度、目口眉の組合せを確認します。表情の印象を損なう転送由来の問題に修正方法が分かるなら直し、十分に仕上がっていれば保存して比較画像とともに返します。単独部品を作り直すたびに全組合せを撮り直す必要はありません。

## 形を判断するときの要点

- まばたきは上瞼約9割・下瞼約1割を出発点に、中央から両端へ移動量を減らします。まつ毛を丸ごと下へ平行移動しません。瞼直上の一列だけ伸びる場合は複数列へ分散させます。
- 基本は「接続のみ」のプロポーショナル編集です。広めに動かす→別の頂点から周辺を戻す、を反復します。分離したまつ毛だけ動くことや、一部癒着で余計な部分が動くことは想定内です。皮膚・部品を順に整えます。
- 正面で閉じても、横で瞼が前へ浮くことがあります。同梱の閉眼素材は前後の動きがほぼないため、8点のフィットだけで奥行きも完成したと扱いません。上下だけでなく前後も頭部の曲面に沿わせます。口も同様です。Tripo由来の非対称トポロジーへXミラーの頂点編集を前提にしません。
- まばたきで眉が下がると悲しそうになります。通常顔の眉と印象を戻し、その下の皮膚をなだらかに配り直します。眉の感情表現は別キーで加えます。
- 口角だけで笑顔を作らず、上下唇・中央・厚み・周辺を合わせて見ます。テクスチャの線だけで本来の口を決めません。

必要なときだけ読む資料：構造と部位特定は[解剖・変形](references/anatomy.md)、症状があるときは[診断](references/diagnostics.md)、完成判断は[見た目の基準](references/visual-quality.md)。

## 見本と記録

同梱ポーズは動きの参考です。別の顔立ちへ移す際は本人らしさを優先し、必要なら固定カメラの通常顔から画像生成で目標を作ります。正面・45度・横の同じ位置を保ち、髪・眉・顔立ちが生成で変わっていないか確認します。目標がすでにあるなら再生成は不要です。

短い記録で十分です。「目標との差→変更→前後画像→採否→次の1手」とユーザー評価を制作フォルダーへ残します。数値検査は破損防止の補助です。観察できない、構造が判断できない、または新しい面が必要な場合は、画像と理由を添えて相談します。回数だけで修正を打ち切ったり、未確認の見た目を合格としません。

## 保持するもの

原本、Basis、既存キー、UV、面構成、既存材質を保持します。口内・歯・舌・テクスチャを新造して欠点を隠しません。目の表示に必要なMToon変換は表示用コピーで行います。対象モデルの番号・座標はその制作フォルダーにだけ保存し、共通ツールへ埋め込みません。髪なしで形を確認してよいですが、最後は髪付きの印象も見ます。

成果は独立した任意データとして同じプロジェクトへ返します。既存VRMへ自動登録せず、全VRM表情を要求する旧形式にも合わせません。これは顔の形状が異なるモデルへ適用する道具であり、どの構造でも無修正で完成するという保証ではありません。
